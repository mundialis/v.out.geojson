## DESCRIPTION

*v.out.geojson* exports GRASS GIS vector map to GeoJSON format into
projection with given EPSG code.

## EXAMPLES

### Export vector map as GeoJSON in EPSG:4326

```sh
v.out.geojson input=vhr output=- epsg=4326
```
